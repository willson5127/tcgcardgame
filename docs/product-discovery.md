# tcgcardgame 需求訪談

## 已確認

- 產品為可實際打牌的多 TCG 平台，也提供卡片收藏管理與組牌。
- 不提供交易等商業功能。
- 長期目標是容納現有與未來的 TCG，透過匯入卡圖、卡片規則、牌局規則及牌局布局格式加入或刪除遊戲。
- 第一個驗收遊戲為 hololive OFFICIAL CARD GAME（ホロカ）；參考 holoDelta 及 Holoduel。
- 第一版驗收為查詢卡表、組牌及匯出 JSON 牌組。實際對局與收藏管理列入後續里程碑。
- 平台使用自己的通用牌組格式，另提供 holoDelta 與 Holoduel 相容匯入／匯出；外部格式欄位待原始碼及樣本核對。
- 每個遊戲可附帶規則程式，卡圖、卡片資料與布局採資料匯入；自動判定能力逐步補齊，新機制可擴充平台能力。
- 一般玩家可從介面匯入及移除遊戲套件，先在本機使用，不設公開套件商店。
- 目前不考慮登入機制及前後台管理權限機制。
- 以第二款規則不同的 TCG 檢驗擴充能力；遊戲及驗收時程待定。
- 初期平台為桌面瀏覽器，對局以同機雙人驗證規則與操作。
- 介面以繁體中文為主。
- 第一版提供介面上的遊戲套件匯入／移除，切換卡表及組牌規則；對局布局與卡片效果執行留待後續。
- 提供可直接使用的 hololive 套件，定義平台套件格式；外部原始資料經轉換工具整理成套件再匯入。資料來源與涵蓋範圍待查證及確認。
- 卡表支援名稱、卡號、效果文字搜尋、卡片詳情及套件定義的屬性篩選。
- 卡片內容保留來源語言，有翻譯時可切換。
- 允許編輯、儲存及匯出未完成或違規牌組，持續顯示違規原因，匯出前提示並請玩家確認。
- 外部格式無法表達牌組內容時須列出問題，不得默默遺失資料；具體阻擋或轉換流程待定。
- 套件與牌組自動保存在目前瀏覽器，並可匯出備份。
- 移除套件時保留牌組，標示「缺少遊戲套件」；重新匯入相符套件後可恢復使用。
- 第一版必須提供通用 JSON、holoDelta 及 Holoduel 的雙向匯入／匯出，以實際樣本驗證並記錄資訊保留範圍及限制。

## 第四輪已確認：卡片身分與資料生命週期

- 區分規則上的卡片與卡片版本，可指定異圖及語言；同名卡張數限制依遊戲規則合併計算。外部格式無法保留版本時，匯出前說明。
- 未知卡片保留原始識別碼並標示待解析，可檢視與備份；補齊相符資料後重新解析，不自動替換或刪除。
- 套件更新前顯示變更摘要，更新後保留牌組及卡片選擇，重新列出違規與缺失。
- 牌組記錄建立或最後驗證時所用套件版本；第一版以目前安裝版本驗證，不提供歷史賽制切換。
- 套件匯入後可離線查卡、看圖、組牌及匯出，完整套件包含必要卡圖與資料。
- 支援單副牌組匯出及完整備份／還原，完整備份包含套件、卡圖及牌組。
- 第一版提供套件格式文件、範例及驗證工具，視覺化套件編輯器留待後續。
- 牌組支援命名、複製、刪除、加入卡片、增減數量及選擇版本；顯示套件定義的分區、張數與違規清單，編輯時自動儲存。

## 第五輪已確認：規則、匯入與還原

- 第一版以結構化規則描述組牌限制，明確列出支援條件；無法表達的規則由驗證工具指出，任意規則程式執行留待後續。
- 套件先完整驗證再一次匯入，阻擋性錯誤使整包失敗並保留原有資料；錯誤須指出位置，非阻擋性問題顯示警告。
- 完整離線套件缺少必要卡圖屬於阻擋性錯誤。
- 重複匯入先比對：新版本顯示更新摘要，相同內容提示已安裝，同版本不同內容或降版需顯示衝突並請玩家確認；更新失敗保留原版本。
- 第一版採合併還原，預覽新增與衝突，相同內容略過；衝突牌組保留兩份並重新命名，套件衝突由玩家選擇，全部驗證成功後才寫入。
- 首次載入且完成離線準備後，可關閉瀏覽器並在離線時重新開啟。
- 第一版正式驗收桌面 Chrome 與 Edge，其他瀏覽器後續擴展。
